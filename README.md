# VSTORepair

Windows 桌面工具：诊断并修复 Word / WPS 文字插件相关的 **COM 类型库** 问题，并管理 **COM / VSTO 加载项**。

常见场景包括插件报错「找不到元素 `0x8002802B`」「库没有注册 `0x8002801D`」、加载项被禁用或加载失败等。

## 功能

### COM 组件修复
- 扫描本机类型库 / 接口注册状态（诊断只读）
- 可粘贴插件弹出的错误文字，额外检查其中提到的接口
- 清理残缺类型库版本等可自动修复项，**修复前备份，可撤销**
- 修复时若检测到 WPS（`wps` / `et` / `wpp`）仍在运行会先阻止，避免写注册表冲突

### 插件管理
- 列出 Word / WPS 文字的 COM、VSTO 加载项（含已禁用、加载失败断开）
- 启用 / 禁用加载项
- 管理 WPS 白名单 / 黑名单相关登记
- 修改后需**完全退出并重新打开** WPS / Word 才会生效

## 环境要求

- Windows 10 / 11（x64）
- [.NET Framework 4.7.2](https://dotnet.microsoft.com/download/dotnet-framework/net472) 或更高
- **以管理员身份运行**（清单已要求提升权限；用于读写相关注册表）

## 构建

```powershell
dotnet build VSTORepair.csproj -c Release
```

产物：`bin\Release\net472\VSTORepair.exe`

## 使用

### 图形界面

双击运行 `VSTORepair.exe`（会请求管理员权限）。

| 页签 | 操作 |
|------|------|
| COM 组件修复 | **诊断** → 查看报告 → **修复**；需要时可 **撤销上次修复** |
| 插件管理 | **刷新** 列表后启用/禁用，或调整白名单 |

其他按钮：复制日志、打开日志目录。

### 命令行

适合脚本或远程排查。结果默认写入数据目录下的 `last-result.txt`，也可用 `/out:` 指定路径。

```text
VSTORepair.exe /scan [/out:文件] [/iid:{GUID或错误片段}]
VSTORepair.exe /fix  [/out:文件] [/iid:{GUID或错误片段}]
VSTORepair.exe /undo
```

| 参数 | 说明 |
|------|------|
| `/scan` | 只诊断，不修改系统 |
| `/fix` | 诊断并尝试修复 |
| `/undo` | 撤销最近一次修复（按备份时间取最新） |
| `/out:路径` | 将报告写入指定文件 |
| `/iid:...` | 传入错误文字或接口 GUID，供额外检查 |

**退出码（`/scan`）**

| 码 | 含义 |
|----|------|
| `0` | 未发现问题 |
| `1` | 有问题，但无法自动修复 |
| `2` | 有问题，且可自动修复 |

**退出码（`/fix`）**

| 码 | 含义 |
|----|------|
| `0` | 修复后复查正常 |
| `1` | 仍有问题或修复失败 |
| `3` | 被阻止（例如 WPS 仍在运行、运行身份与桌面登录用户不一致） |

## 数据目录

`%LocalAppData%\VSTORepair`

| 内容 | 说明 |
|------|------|
| `last-scan.txt` / `last-result.txt` | 最近一次扫描或命令行结果 |
| `backup\yyyyMMdd-HHmmss\` | 每次修复的备份与操作日志，供撤销使用 |

## 注意事项

1. 修复前请**完全退出 WPS**（含托盘图标）。
2. 请直接在本机桌面用户下以管理员运行；不要用其他账号“代提权”，否则可能只改到错误用户的注册表。
3. 撤销只针对本工具写入的最近一次备份；手动改过的注册表不在自动恢复范围内。
4. 本工具会修改系统注册表，请在确认问题后再执行修复。
